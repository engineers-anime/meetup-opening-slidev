# 勉強会オープニング生成ツール

connpass のイベントURLから、参考資料の流れに沿って、表紙、自己紹介、会の説明、注意事項、タイムテーブル、会場案内、ハッシュタグ、トーク開始・終了、宣伝と次回予告を Slidev で生成します。タイムテーブルはセルの文字量に合わせてページを分けます。

## セットアップ

Node.js 22.18 以降の 22 系、または 24.11 以降で実行します。

```sh
npm ci
```

生成スクリプトの TypeScript は `tsx` で実行します。上記の Node.js バージョンは Slidev とその依存パッケージの対応範囲です。

## 主催者や勉強会が変わるとき

イベントURLを入力する前に、プロジェクト直下の `opening.json` を編集します。同梱の自己紹介と会の説明はエンジニアニメ向けの記入例です。

```json
{
  "host": {
    "name": "山田 はな",
    "job": "フロントエンドエンジニア",
    "hobby": "写真を撮ること"
  },
  "about": [
    "Web制作で学んだことを持ち寄る勉強会です。",
    "発表の後は、参加者同士で気軽に交流しましょう。"
  ],
  "notes": [
    "スライドを撮影する前に登壇者の許可を取ってください。",
    "退出時は忘れ物がないかご確認ください。"
  ]
}
```

| 設定 | 投影される内容 |
| --- | --- |
| `host.name`、`host.job`、`host.hobby` | 自己紹介の名前、仕事、趣味 |
| `about` | 会の説明。配列の1項目が1段落になります。 |
| `notes` | 注意事項。配列の1項目が箇条書きの1行になります。 |

プロフィール画像を出す場合は、プロジェクト直下に `public/` を作り、新しい主催者の画像を `public/host.png` として置きます。正方形の画像が向いています。画像がなければ、自己紹介はテキストだけで表示されます。

設定や画像を変更したら、`npm run opening` でもう一度生成します。日時・会場・進行表・ハッシュタグは、入力したイベントURLから読み取ります。

## URLから生成して開く

表示されたプロンプトに connpass のイベントURLを貼り付けて、Enter を押します。

```sh
npm run opening
```

タイムテーブルを取得できない場合は生成を中断し、既存のスライドを残します。

次回予告には同じグループで今回より後に始まる公開イベントのうち、最も近いものを表示します。ページ取得ではグループトップの開催予定欄を使います。告知したいイベントが決まっていれば、`--next <次回のconnpass URL>` で指定できます。次回が未公開だと分かっている場合は `--no-next` を使えます。

初回は `npm run opening` でローカルの `slides.md` を生成します。投影だけなら `npm run dev`、生成だけなら `npm run generate -- <URL>`、静的ビルドなら `npm run build` を実行します。
